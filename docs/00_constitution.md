# 00-X. K-AGRI Knowledge Graph 원칙

K-AGRI의 모든 데이터는 단순 저장하지 않는다.

모든 자료는 반드시 아래 구조 중 하나에 연결한다.

농민 / 작물 / 지역 / 시기 / 상황 / 문제 / 원인 / 해결 / 결과 / 감정 / 제품 / 회사 / 콘텐츠 / CRM / 캠페인 / 매출

K-AGRI의 목적은 자료 보관이 아니라
대한민국 농업 현실을 학습하고
콘텐츠, 상담, CRM, 사업 제안, 매출로 연결하는 것이다.
