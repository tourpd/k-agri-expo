# K-AGRI MASTER MEMORY (베이스캠프)

최종 업데이트: 2026-06-18

## 프로젝트 철학

K-AGRI는 박람회가 아니다.
K-AGRI는 대한민국 농업의 데이터, 판단, 실행을 연결하는 AI 운영체제(OS)다.

자료 → 데이터 → 판단규칙 → 행동지시 → 콘텐츠 → 거래 → 수익

---

## K-AGRI AI 두뇌센터

### 목표
농업자료를 AI가 이해 가능한 판단규칙으로 변환한다.

### 완료
- PPT 업로드
- PDF 변환
- OCR 추출
- 이미지 추출
- GPT 판단규칙 추출
- knowledge_rules 저장 성공

### 중요 결정
판단규칙과 제품명을 분리한다.

판단규칙
- 작물
- 월
- 생육단계
- 증상
- 원인
- 대책
- 행동지시

제품정보
- 제품명
- 제품종류
- 사용목적
- 주의사항

별도 테이블:
knowledge_rule_products

## 현재 최우선 작업

1. 판단규칙 DB 검색기

3. 판단규칙 → 작가실 연결
4. 갈색거저리 사육일지 DB 구축
5. AI 사육코치 구축
6. AI 뉴스 엔진
7. AI 쇼츠 엔진
