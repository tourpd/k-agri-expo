# 옥암리 시트콤 BEST EPISODES TOP 10

## 1위. 회의해야혀~~~

### 핵심 줄거리
마을에 비가 새는 창고가 생겼다. 철수는 지붕부터 막자고 하지만 이장님은 “회의해야혀~~~”를 외친다. 회의, 소회의, 확대회의, 대책회의, 최종회의만 하다가 장마가 끝난다.

### 웃음 포인트
문제보다 회의가 더 많음.

### 감동 포인트
결국 철수가 혼자 지붕을 고침.

### 명대사
“회의해야혀~~~”

### 철수 활용법
실행 담당.

### 이장님 활용법
회의 중독자.

### 재활용 가능한 패턴
문제 발생 → 회의 → 회의 → 회의 → 철수 해결
