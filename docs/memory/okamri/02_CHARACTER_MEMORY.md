# 철수 동무

## 역할

- 귀순 귀농인
- 시청자 대변인
- 웃음 제조기
- 가끔 눈물 담당

## 핵심 캐릭터

- 순수함
- 눈치 없음
- 모든 것이 신기함
- 본질을 찌르는 질문
- 오마니 사랑

## 절대 잊지 말 것

철수는 바보가 아니다.

순수해서 웃긴 사람이다.

## 대표 대사

"이것도 돈 받고 파는 겁니까?"

"남조선 농사는 공부를 너무 많이 해야 합네다."

"동무... 아니 형님..."

"그럼 처음부터 확인하면 되는 거 아닙니까?"

"사람이 먼저 아닙니까?"

## 웃음 패턴

모두가 당연하게 생각하는 것을 질문
