# 프로젝트명

자료화면 AI DB센터 (Visual Knowledge Center)

# 탄생 배경

K-AGRI가 단순 문서 저장소가 아니라 PDF·PPT·사진·표·그래프를 AI가 이해하는 농업 두뇌로 발전하기 위해 시작.

# 왜 시작했는가

농진청 자료, 안이영 소장 교육자료, 병해충 자료, 방송 자료가 흩어져 있고 검색·활용이 어려움.

# 해결하려는 문제

- PDF 안의 사진·표·그래프 활용 불가
- 농업 지식이 문서에 갇혀 있음
- 방송·쇼츠·상담·판단규칙으로 연결 안 됨
- 사람이 일일이 찾아야 함

# 기존 방식의 한계

- PDF 파일 보관 수준
- 이미지 검색 불가
- AI 분석 불가
- 작물·병해충·행동지시 연결 불가

# 핵심 철학

문서를 저장하는 것이 아니라

"이미지와 지식을 AI 자산화한다."

# 무엇을 가장 중요하게 보는가

1. 이미지가 보여야 한다
2. 운영자가 한눈에 이해해야 한다
3. AI 분석 결과가 실제 활용으로 연결돼야 한다
4. 공동편집이 가능해야 한다

# 주요 결정사항

## 확정된 내용만

- DB 테이블: knowledge_visual_pages
- PDF → 이미지 추출 후 저장
- 이미지 중심 관리
- 엑셀형 관리화면 유지
- 페이지 정렬 가능
- 필터·검색 가능
- AI 정밀분석 버튼 운영
- 행 클릭 시 상세 분석창 예정
- 공동편집 영역 추가 예정

# K-AGRI 전체에서의 의미

K-AGRI 두뇌센터의 시각자료 기억장치.

# 이 프로젝트가 전체 K-AGRI 구조에서 담당하는 역할

자료 → 이미지 → AI분석 → 판단규칙 → 방송 → 쇼츠 → 상담 → 행동지시

모든 농업 AI의 원천 데이터 공급센터 역할.

# 베이스캠프 요약

자료화면 AI DB센터는 PDF·PPT에서 추출한 사진·표·그래프를 DB화하여 K-AGRI AI 두뇌의 시각 기억으로 만드는 프로젝트다. 현재 이미지 추출·DB 저장·썸네일 관리·검색·정렬 기능까지 완료되었다. 앞으로 GPT Vision 분석, 공동편집, 작물·병해충 자동분류, 행동지시 생성, 방송·쇼츠 소재 연결까지 확장한다. K-AGRI 전체에서 지식자산센터와 판단엔진을 연결하는 핵심 입력센터 역할을 담당한다.
