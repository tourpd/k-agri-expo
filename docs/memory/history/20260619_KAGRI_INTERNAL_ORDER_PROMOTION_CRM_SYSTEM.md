# 프로젝트명

K-AGRI EXPO 내부 주문·프로모션·CRM 시스템

---

# 탄생 배경

기존 제품 상세페이지가 외부 구매링크 중심 구조였음.

하지만 상당수 업체는 자체 쇼핑몰이 없고,
체험단 모집, 샘플 공급, 공동구매, 대리점 모집 형태가 많음.

따라서 단순 구매링크가 아니라
K-AGRI 내부에서 신청 → 접수 → 상담 → 판매까지 연결하는 구조가 필요해짐.

---

# 왜 시작했는가

- 외부몰 없는 업체도 판매 가능
- 농민 체험단 운영
- 공동구매 운영
- 대리점 모집
- 바이어 발굴
- 주문 데이터를 K-AGRI 자산으로 축적

---

# 해결하려는 문제

- 구매링크 없는 업체 판매 불가
- 주문 데이터 축적 불가
- 고객 정보 확보 불가
- CRM 운영 불가
- 프로모션 이유 없이 가격만 할인

---

# 기존 방식의 한계

- "지금 구매하기" 버튼만 존재
- 왜 싸게 파는지 설명 없음
- 체험단/공동구매 구조 없음
- 신청 데이터 저장 안됨
- 관리자 추적 불가

---

# 핵심 철학

"제품을 파는 것이 아니라 이유를 판다"

가격 → 신청

이유 → 조건 → 한정수량 → 신청

구조로 전환

---

# 무엇을 가장 중요하게 보는가

- 농민이 신청 이유를 이해해야 함
- 업체가 프로모션 명분을 설명해야 함
- 주문 데이터를 K-AGRI가 확보해야 함
- 외부몰 없이도 판매 가능해야 함

# 베이스캠프 요약

주문 시스템 1차 베이스캠프 완료.

expo_orders 테이블과 주문 API를 구축했고 ProductOrderBox를 통해 외부 쇼핑몰 없이도 제품 신청이 가능해졌다.

구매링크 강제 정책은 폐기하고 내부 신청 구조를 채택했다.

핵심 철학은 "가격이 아니라 신청 이유를 판다"이며 앞으로 모든 제품은 프로모션 목적 → 신청 이유 → 참여 조건 → 한정 수량 → 가격 구조를 사용한다.

다음 단계는 프로모션 필드 저장 및 관리자 CRM 구축이다.
