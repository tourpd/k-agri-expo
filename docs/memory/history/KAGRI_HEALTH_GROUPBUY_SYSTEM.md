# 베이스캠프 요약

한국농수산TV 건강공동구매관은 MSM 관절건강 제품을 대상으로 구축된 K-AGRI 최초의 실전 판매 시스템이다. 공동구매 랜딩페이지와 전용 주문페이지를 구축했으며 전화번호 자동포맷, 주소검색, 입금안내, 주문접수 기능을 구현했다. 현재 UI는 거의 완성되었고 마지막 과제는 고령 농민 기준의 수량선택 UX 개선과 주문 API·OMS 연동 검증이다. 향후 K-AGRI 전체 상품 판매 시스템의 표준 모델로 사용한다.
