# 프로젝트명

K-Agri Expo 온라인 박람회(가상 전시장·부스 시스템) 구축 프로젝트

---

# 탄생 배경

기존 K-Agri Expo가 브랜드관 중심 구조로 발전했지만, 실제 박람회처럼 업체를 탐색하고 상담하는 경험이 부족했음.

농민·기업·바이어가 온라인에서도 실제 전시장을 둘러보는 느낌을 제공하기 위해 시작.

---

# 왜 시작했는가

- 온라인 박람회 구현
- 업체 노출 극대화
- 상담 전환율 향상
- 기업 입점 가치 상승
- 향후 유료 부스 판매 기반 구축

---

# 해결하려는 문제

- 업체가 단순 리스트로만 보임
- 박람회 현장감 부족
- 업체 간 차별화 어려움
- 상담 연결 구조 약함
- 프리미엄 부스 판매 불가

---

# 기존 방식의 한계

- 브랜드 목록 나열
- 업체 상세 진입률 낮음
- 전시장 개념 없음
- 부스 위치 개념 없음
- 박람회 운영 수익화 어려움

---

# 핵심 철학

"온라인에서도 실제 박람회처럼 걷고 둘러본다."

"부스는 광고가 아니라 영업 공간이다."

---

# 무엇을 가장 중요하게 보는가

1. 농민이 쉽게 둘러볼 수 있어야 함
2. 업체 상담으로 연결되어야 함
3. 부스 자체가 매출을 만들어야 함
4. 모바일 우선

# 베이스캠프 요약

K-Agri Expo는 단순 브랜드 목록 구조를 넘어 실제 박람회형 온라인 전시장으로 발전 중이다.

booths, slots, hall 구조를 확정했고 농자재관(agri-inputs)에 A1~B3 슬롯을 구성했다.

도프·한국농수산TV·DOFagro 부스가 생성되었으며 슬롯 연결 작업이 진행 중이다.

업체당 다중 부스를 허용하기로 결정했다.

현재 전시장 지도 UI와 확대/축소 기능은 구현 완료되었고, 다음 목표는 실제 업체명 표시, 부스 클릭, 부스 상세페이지(/expo/booth/[id]) 연결, 제품·자산·상담 기능 연동이다.

장기적으로는 K-AGRI 전체의 온라인 박람회 플랫폼이자 향후 3D 가상 전시장으로 확장 가능한 핵심 기반 시스템이다.
