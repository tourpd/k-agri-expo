# 프로젝트명

K-AGRI 농산물거래소 (Agri Exchange) 리빌드 프로젝트

---

# 탄생 배경

기존 농산물거래센터가 “설명하는 배너” 역할만 하고 실제 거래가 일어나는 구조가 아니었음.

---

# 왜 시작했는가

농민이 보유한 저장농산물을 전국 바이어에게 판매하고,

바이어는 전국 농산물을 쉽게 검색하고 거래할 수 있는 B2B 거래시장을 만들기 위해.

---

# 해결하려는 문제

- 농민은 팔 곳이 없음
- 바이어는 물건 찾기 어려움
- 거래 정보가 흩어져 있음
- 가격 협상과 계약 과정이 비효율적임

---

# 기존 방식의 한계

기존 “농산물거래센터”

- 설명 위주
- 거래소 느낌 부족
- B2B 느낌 부족
- 농민·바이어 행동 유도 부족
- 실제 거래 시작점이 아님

---

# 핵심 철학

“거래를 설명하지 말고 거래를 시작하게 만들어라.”

# K-AGRI 전체에서의 의미

농산물 자산센터가 생산자 자산화라면,

농산물거래소는

자산 → 거래 → 계약 → 정산

으로 연결하는 핵심 엔진.

---

농산물 자산센터
↓
K-Agri 농산물거래소
↓
거래제안센터
↓
인증바이어센터
↓
계약·정산센터

---

# 베이스캠프 요약

K-Agri 농산물거래소는 기존 농산물거래센터를 폐기하고 새로 정의한 B2B 거래 플랫폼이다. 독립 사이트가 아니라 K-Agri Expo 내부 핵심 기능으로 운영한다. 농민은 농산물을 등록하고, 바이어는 전국 농산물을 검색하며, 거래제안·화상상담·계약·정산까지 연결한다. 현재 등록·검색·거래관리 페이지는 생성 완료되었고, 다음 단계는 카드형 화면을 폐기하고 바이어 중심의 엑셀형 거래소 UI로 전환하는 것이다. 핵심 목표는 “농민이 물건을 올리고 바이어가 찾는 실제 거래시장”을 만드는 것이다.
