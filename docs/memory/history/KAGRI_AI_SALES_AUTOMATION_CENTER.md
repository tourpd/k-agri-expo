# 프로젝트명

K-Agri Expo AI 판매자동화센터

---

# 탄생 배경

업체들이 PDF 카탈로그, 홈페이지, 쇼핑몰, 유튜브, 블로그에 제품 정보가 흩어져 있고 이를 다시 엑스포 브랜드관·상세페이지·공동구매용으로 수작업 정리하는 데 시간이 많이 소요됨.

---

# 왜 시작했는가

자료만 넣으면 AI가 제품을 추출하고 편집·추천·상세페이지 제작·브랜드관 등록까지 자동화하기 위해 시작.

---

# 해결하려는 문제

- 제품 등록 수작업
- 상세페이지 제작 수작업
- 브랜드관 구축 시간 과다
- 제품 정리 및 추천 구성 작업 비효율
- 동일 PDF 반복 분석

---

# 기존 방식의 한계

- PDF 분석 후 결과만 출력
- 제품 수정 불가
- 추천상품 구성 불가
- 상세페이지 제작 연결 없음
- 홈페이지/쇼핑몰 URL 분석 미구현
- 동일 자료 재분석 필요

---

# 핵심 철학

AI 판매자동화센터는 PDF 분석기가 아니다.

"AI 상품기획자 + AI 브랜드매니저 + AI 상세페이지 제작기 + AI 엑스포 등록센터"

를 만드는 것이 목표.

---

# 무엇을 가장 중요하게 보는가

분석보다 실행.

즉,

분석
→ 편집
→ 추천구성
→ 상세페이지
→ 브랜드관 등록

까지 이어져야 함.

---

# 주요 결정사항

- PDF + 홈페이지 + 쇼핑몰 + 유튜브 + 블로그 통합 분석
- 분석 중에도 제품 실시간 표시
- 진행률은 조각수(2/6)가 아니라 실제 % 기반 표시
- 전체 제품 리스트는 엑셀형 표 유지
- 제품 발견 보드는 카드형 유지
- 제품 편집실 별도 구축
- 10개 추천 / 20개 추천 자동 구성
- 상세페이지 제작센터 구축
- PDF 캐시 적용
- URL 실제 분석 기능 추가
- 브랜드관 등록 자동 연결

# 베이스캠프 요약

AI 판매자동화센터는 단순 PDF 분석기가 아니다.

자료를 넣으면 AI가 제품을 추출하고, 업체가 편집한 뒤, 대표상품·10개·20개 구성을 만들고, 상세페이지를 자동 제작하여 K-Agri Expo 브랜드관에 등록하는 판매자동화 엔진이다.

현재는 제품 추출·추천구성 단계까지 완료되었으며, 다음 핵심 작업은 제품 편집실과 상세페이지 제작센터 구축이다.
