# 프로젝트명

K-Agri Expo AI 판매자동화센터

# 탄생 배경

K-Agri Expo가 단순 박람회·쇼핑몰이 아니라 AI가 판매를 대신 수행하는 플랫폼으로 발전하면서 시작.

# 왜 시작했는가

업체가 마케팅을 몰라도 제품 사진·PDF·유튜브만 올리면 광고, 쇼츠, 공동구매, CRM, 재구매까지 자동 생성하기 위해.

# 해결하려는 문제

- 농업 업체의 마케팅 역량 부족
- 판매페이지 제작 비용
- 광고 제작 비용
- CRM 부재
- 재구매 관리 부재
- 고객 데이터 활용 부족

# 기존 방식의 한계

- 제품 등록만 하고 판매는 업체 책임
- 광고·쇼츠·CRM이 분리됨
- 고객 성향 데이터 축적 안 됨
- 재구매 및 추천판매 자동화 없음

# 핵심 철학

"제품을 파는 것이 아니라 고객을 이해하고 평생 고객으로 만든다."

# 무엇을 가장 중요하게 보는가

- 상담
- 주문
- 공동구매
- 매출
- 재구매
- 고객 생애가치(LTV)

# 주요 결정사항

- 제품명/타겟/고민 직접 입력 방식 폐기
- 제품사진 + PDF + 유튜브 기반 AI 분석
- 광고 → 쇼츠 → 영상 → CRM → 재구매 자동 연결
- 고객 욕망 분석 기반 판매전략 생성
- 관리자 화면은 전부 엑셀형 UI
- 카드형 운영화면 폐기

# 확정된 내용만

- AI 판매전략 API 구축
- CRM 자동 태그 생성
- 재구매 예측 포함
- 추천상품 전략 포함
- 공동구매 전략 포함
- 문자 자동화 포함
- 고객 성향 분석 포함

# 폐기한 아이디어

- 제품명 직접 입력
- 타겟 고객 직접 입력
- 고객 고민 직접 입력
- 카드형 판매자동화센터

# 버린 방향과 이유

- 입력형 마케팅 툴 → AI 자동분석형
- 카드형 관리자 UI → 데이터 확장성 부족
- 단순 광고 생성기 → 매출 연결 약함

# K-AGRI 전체에서의 의미

# 이 프로젝트가 전체 K-AGRI 구조에서 담당하는 역할

지식자산센터가 정보를 만들고,

AI 판매자동화센터가 그것을 매출로 전환한다.

# 베이스캠프 요약

K-Agri AI 판매자동화센터는 업체가 제품사진·PDF·유튜브만 올리면 AI가 제품분석, 고객욕망분석, 광고, 쇼츠, 영상, 배너, 문자, 공동구매, CRM, 추천상품, 재구매 전략까지 자동 생성하는 플랫폼이다. 목표는 조회수가 아니라 상담·주문·공동구매·매출·재구매다. 앞으로 고객을 농자재 구매자가 아니라 건강·가족·선물·생활불편·돈·감정·시즌 욕망을 가진 사람으로 분석하는 쿠팡급 고객분석 엔진으로 확장한다. 관리자 화면은 모두 엑셀형 UI로 통일한다.
