# 프로젝트명

K-AGRI EXPO 업체 부스 운영·판매관리 시스템

---

# 탄생 배경

기존 K-AGRI EXPO는 전시장 관람 중심 구조였으나 실제 업체가 직접 제품을 등록·수정·홍보하고 상담을 받을 수 있는 운영 시스템이 부족했음.

---

# 왜 시작했는가

- 업체 자율 운영
- 운영자 개입 최소화
- 제품 등록 자동화
- 온라인 박람회 실현
- AI 판매자동화센터 연계
- 유료 부스 모델 구축

---

# 해결하려는 문제

- 업체가 직접 부스를 운영하지 못함
- 제품 홍보 자료 등록 불가
- 제품 이미지·카탈로그 관리 불가
- 유튜브 설명 자료 연결 불가
- 요금제별 기능 차별화 부재
- 로그인 체계 분산

---

# 기존 방식의 한계

- 단순 부스 정보만 관리
- 제품 설명 수준에 머무름
- 이미지 없음
- 카탈로그 없음
- 영상 없음
- 플랜별 제한 없음
- vendor 인증 구조 불안정

---

# 핵심 철학

"부스는 웹페이지가 아니라 온라인 전시장이다."

"업체가 직접 꾸미고 직접 판매한다."

"부스 → 제품 → 상담 → 주문 → CRM까지 연결한다."

# 베이스캠프 요약

K-AGRI EXPO 업체 부스 운영 시스템은 관리자 중심 구조를 폐기하고 업체가 직접 운영하는 온라인 전시장 구조로 전환되었다.

vendor ↔ booth 연결, 제품 등록·수정·삭제, 공개 부스 연결, 인증 구조, 저장 기능이 대부분 완성되었다.

block_publish_toggle_by_non_admin() 트리거 문제도 해결되어 부스 저장이 정상화되었다.

현재 핵심 과제는 Admin·Vendor·Farmer·Buyer 통합 로그인 체계 구축과 부스 고도화(제품 이미지, 유튜브, PDF 카탈로그, 상담 기능)이다.

향후 BASIC·PREMIUM·VIP 모델별 제품 수 제한을 적용하고 AI 판매자동화센터와 연결하여 K-AGRI의 핵심 수익 플랫폼으로 발전시키는 단계에 진입했다.
