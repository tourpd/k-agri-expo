# 프로젝트명

K-AGRI EXPO 라이브 방송 전화추첨 시스템

# 탄생 배경

K-AGRI EXPO 라이브 방송에서 농민 대상 경품 이벤트를 진행하기 위해 시작.

초기에는 라이브 URL 인증 + 암호 입력 + 추첨 구조를 설계했으나 운영 복잡도가 높아짐.

# 왜 시작했는가

- 농민 참여율 증가
- 라이브 방송 시청 유도
- 협찬사 제품 홍보
- 방송형 이벤트 콘텐츠 구축

# 해결하려는 문제

- 라이브 참여자 확보
- 공정한 추첨 운영
- 방송 몰입도 향상
- 협찬사 노출 시간 확보
- 당첨자 검증

# 기존 방식의 한계

- 라이브 URL 입력
- 인증 암호 입력
- 고령 농민에게 복잡
- 참여 이탈 가능성 높음
- 방송 진행 흐름 끊김
- 운영자 실수 가능성 증가

# 핵심 철학

"복잡한 인증보다 방송형 전화추첨"

"시스템은 관리하고 사람은 방송한다"

# 무엇을 가장 중요하게 보는가

- 농민이 쉽게 참여할 것
- 방송 몰입도가 높을 것
- 협찬사 홍보 시간이 확보될 것
- 운영자가 실수하지 않을 것
- 현장에서 바로 운영 가능할 것

# K-AGRI 전체에서의 의미

라이브 방송을 단순 홍보가 아닌 "참여형 농민 이벤트 플랫폼"으로 발전시키는 핵심 시스템.

# 이 프로젝트가 전체 K-AGRI 구조에서 담당하는 역할

- 라이브 방송 운영
- 농민 참여 유도
- 협찬사 노출
- 공동구매 연결
- 브랜드 홍보
- 고객 DB 확보
- 방송형 커머스 구축

# 베이스캠프 요약

초기 라이브 인증 시스템은 암호 입력 후 유튜브 이동 구조였으나 운영 복잡성이 높아 전화추첨 방식으로 전환했다.

현재는 라이브 URL 저장 및 이동 기능이 정상 동작하며, 최종 방향은 사전 참여자 → 랜덤 추첨 → 전화 연결 → 당첨 확정 구조다.

자동전화와 암호 인증은 폐기했고, 사람이 직접 전화하는 방송형 구조를 채택했다.

다음 단계는 live_draw DB 구축, 추첨 API 3종 구현, 관리자 추첨 화면 구축, 방송용 디스플레이 화면 구축이다.

K-AGRI 라이브 이벤트의 기준 베이스캠프로 확정.
