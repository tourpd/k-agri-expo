# 탄생 배경

K-Agri Expo에 참가하려는 업체들이 회원가입 후 입점신청 과정에서 반복적으로 오류가 발생하고, 신청 구조가 복잡해 실제 입점 전환율이 낮아짐.

---

# 왜 시작했는가

- 업체 입점률 향상
- 신청 과정 단순화
- 운영자 업무 감소
- 세금계산서 발행 정보 자동 확보
- 향후 브랜드관/부스 자동 생성 기반 구축

---

# 해결하려는 문제

- 회원가입 후 입점신청 혼란
- 상품 선택 구조 복잡
- 업체 정보 직접 입력 부담
- 사업자 정보 누락
- 기존 신청 테이블 충돌
- 반복적인 500 오류

---

# 기존 방식의 한계

- 상품 카드가 너무 많음
- 부스 종류와 기간 구분 불명확
- 가격 비교 어려움
- 사업자 정보 수기 입력
- vendor_applications 구조 복잡
- 정책(RLS) 충돌 발생
- 신청 후 흐름 이해 어려움

# 베이스캠프 요약

K-Agri Expo 벤더 입점 시스템은 기존 상품 중심 신청 구조를 폐기하고, 부스 선택 → 기간 선택 → 사업자등록증 업로드 → 자동입력 → 신청 제출 구조로 재설계하기로 확정했다.

국세청 자동검증은 제외하고 OCR 자동입력만 적용한다.

가격 정책은 무료체험(0원), 일반부스(5만원/12만원), 프리미엄부스(15만원/35만원)으로 확정했다.

기존 vendor_applications의 반복 오류와 정책 충돌을 피하기 위해 vendor_applications_v2 테이블을 사용하기로 결정했다.

현재 설계는 완료되었고, 다음 단계는 page.tsx 적용, OCR API 연결, 신청 저장 API 연결, 완료 페이지 정리다.

이 시스템은 K-AGRI 전체 공급업체가 들어오는 첫 관문이며 향후 브랜드관 생성, 상품 등록, 주문, CRM, AI 판매자동화로 이어지는 핵심 게이트웨이 역할을 담당한다.
