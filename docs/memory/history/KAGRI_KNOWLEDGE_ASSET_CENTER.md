# 프로젝트명

K-AGRI 통합 지식자산센터 (안이영 데이터 자산화 프로젝트)

## 탄생 배경

안이영 소장의 30년 농민교육 PPT, 농업기술센터 자료, 농진청 자료, 포토닥터 사진, 유튜브 영상 등 방대한 농업 지식이 흩어져 있었고 재사용이 어려웠다.

## 왜 시작했는가

농업 자료를 단순 보관하지 않고 농민 행동지시, 콘텐츠, 제품 추천, 매출로 연결하기 위해 시작.

## 해결하려는 문제

- 농업 자료가 죽은 데이터로 방치됨
- 필요한 자료를 다시 찾기 어려움
- 콘텐츠 제작이 매번 처음부터 시작됨
- 농민에게 즉시 활용 가능한 행동지시가 부족함

## 기존 방식의 한계

- OCR → GPT → 판단규칙 자동생성 방식
- "확인하세요", "점검하세요" 수준의 무의미한 결과 다수 발생
- 실제 농민 행동과 매출로 연결되지 않음
- 이미지 AI 분석에 시간 과다 소요

## 핵심 철학

자료 → 판단 → 콘텐츠 → 제품 → 매출

"혼자 고민하는 농사, 함께해서 돈 버는 농사"

## 무엇을 가장 중요하게 보는가

- 농민 행동 변화
- 콘텐츠 생산성
- 제품 판매 연결
- 매출 발생

## 주요 결정사항

- 기존 판단규칙 전량 삭제
- 자료 우선, 규칙은 나중
- 이미지는 분석보다 색인 우선
- PPT·PDF·유튜브·포토닥터·뉴스를 통합 자산으로 관리
- 카드형 UI 폐기
- 운영용 엑셀형 UI 채택
- 자료 중심 구조로 전환

## 폐기한 아이디어

### AI 자동 판단규칙 대량 생성

이유:
- 품질 낮음
- 현장 활용성 부족
- 농민 행동 유도 실패

### 이미지 의미 자동 분석 중심 구조

이유:
- 느림
- 비용 증가
- 정확도 불안정

## 베이스캠프 요약

안이영 자료를 단순 규칙 생성 프로젝트가 아닌 K-AGRI 핵심 지식자산으로 전환했다. 앞으로는 자료를 보관하는 것이 아니라 색인·재활용하여 농민 행동지시, 콘텐츠, 제품 추천, 공동구매, 매출까지 연결한다. 현재 946페이지 색인이 완료되었으며, 다음 단계는 작물별 농사 캘린더와 콘텐츠 자동 생산 엔진 구축이다.
