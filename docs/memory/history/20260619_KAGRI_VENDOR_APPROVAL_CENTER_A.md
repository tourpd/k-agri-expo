# 프로젝트명

K-AGRI EXPO 입점신청 · 업체승인 · 부스배정 통합 시스템 (A안)

---

# 탄생 배경

K-AGRI EXPO에 업체 입점 신청이 증가하면서 신청 → 입금 → 승인 → 부스 생성 → 전시장 노출까지의 운영 체계를 자동화할 필요가 생김.

---

# 왜 시작했는가

- 업체 입점 프로세스 표준화
- 운영자 수작업 제거
- 승인 상태 추적 가능
- 사업자 검증 체계 구축
- 부스 생성 자동화
- 전시장 운영 안정화

---

# 해결하려는 문제

- 신청은 했는데 진행상태를 알 수 없음
- 승인 버튼 부재
- 입금 확인 기능 없음
- 사업자등록증 확인 불가
- 업체 희망 위치 수집 안 됨
- 부스 배정 체계 없음
- 관리자/업체 화면 역할 혼재

---

# 기존 방식의 한계

- 신청서만 존재
- 승인 프로세스 없음
- 부스 배정 구조 없음
- 사업자등록증 관리 부재
- 신청 상태 확인 화면과 신청 화면 혼재
- 업체와 관리자 권한 구분 부족

---

# 베이스캠프 요약

K-AGRI EXPO 입점승인센터 A안은 업체 신청 → 사업자 검증 → 입금 확인 → 승인 → 슬롯 배정 → 부스 생성까지 관리하는 통합 운영 시스템이다.

업체는 희망관과 희망위치를 선택하지만 실제 위치는 관리자가 배정한다.

미래식량·곤충관을 포함한 6개 관 체계를 사용하며 사업자등록증 업로드는 필수다.

현재 업체 신청, 상태 조회, 업체 대시보드, 리드관리, 부스수정 기능은 구현 완료되었다.

다음 핵심 작업은 /admin/vendor-applications 관리자 승인센터 구축으로 승인·반려·입금확인·사업자등록증 확인·슬롯배정·부스생성 기능을 완성하는 것이다.

이 시스템은 K-AGRI 전체 전시장 운영의 시작점이자 모든 업체가 통과하는 공식 입점 게이트웨이 역할을 담당한다.
