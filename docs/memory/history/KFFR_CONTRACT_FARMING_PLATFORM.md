# 프로젝트명

KFFR 미래농업 계약생산 플랫폼

---

# 탄생 배경

- 농민 고령화
- 청년농 부족
- 농산물 가격 변동성 심화
- 생산은 가능하지만 판매와 수익 안정성이 부족
- 미래식량·곤충·양봉·치유농업을 산업화할 플랫폼 필요

---

# 왜 시작했는가

- 농민이 생산 후 판로 걱정 없이 도전할 수 있는 구조 구축
- 청년농이 실패 위험을 줄이고 농업에 진입할 수 있는 모델 구축
- 생산·수매·가공·판매를 하나의 시스템으로 연결하기 위해 시작

---

# 해결하려는 문제

- 생산 후 판매 불안
- 청년농 정착 실패
- 농업 데이터 부재
- 수매 시스템 부재
- 소비시장 연결 부족
- 지자체 사업과 민간사업의 단절

---

# 기존 방식의 한계

- 교육만 하고 끝남
- 생산만 하고 끝남
- 수매 보장 없음
- 데이터 축적 없음
- 고객 CRM 없음
- 개별 농가 단위 운영

---

# 핵심 철학

- 농사를 물려주지 마십시오. 미래를 물려주십시오.
- 생산보다 산업화
- 교육보다 수익 연결
- 곤충보다 시스템
- 제품보다 데이터

# 베이스캠프 요약

KFFR은 곤충사업 회사가 아니다.

농민을 모집하고 교육하며 생산하게 하고 수매와 가공, 판매까지 연결하는 미래농업 계약생산 플랫폼이다.

핵심 경쟁력은 곤충이 아니라 수매, 데이터, AI, CRM, 한국농수산TV 네트워크다.

연천 프로젝트는 첫 번째 지자체 실증모델이며, 뉴트리킷은 소비시장과 고객데이터 플랫폼 역할을 맡는다.

최종 목표는 생산량 확대가 아니라 농민이 실패하지 않는 미래농업 산업 시스템 구축이다.
