# 프로젝트명

---

# 탄생 배경

기존 K-Agri Expo의 전시장 구조가 실제 농민과 업체 모두에게 매력적이지 않다는 문제 발견.

특히 지도형 부스 구조는 온라인에서 효율이 낮고, 업체가 돈을 내고 입점할 이유가 부족했음.

---

# 왜 시작했는가

- 농민이 새로운 농자재·농기계·기술을 쉽게 발견하게 하기 위해
- 업체가 온라인에서도 실제 농업박람회 이상의 홍보 효과를 얻기 위해
- K-Agri Expo를 단순 쇼핑몰이 아닌 농업 비즈니스 플랫폼으로 만들기 위해

---

# 해결하려는 문제

- 업체 입점 가치 부족
- 온라인 박람회의 낮은 체류시간
- 농민의 정보 부족
- 브랜드 노출 부족
- 농약방 의존 구조
- 농민 데이터와 업체 데이터 연결 문제

---

# 베이스캠프 요약

K-Agri Expo는 지도형 온라인 박람회가 아니라 브랜드 전시장형 Hall 구조로 전환한다. Hall은 작물영양관·병해충솔루션관·농기계장비관·종자육묘관·스마트농업AI관·미래식량곤충관 6개로 확정했다. 농민은 관 → 브랜드관 → 상담 → 공동구매 → 구매 흐름으로 이동한다. 업체는 자기 브랜드관을 직접 운영하며 제품·이벤트·라이브·공동구매를 관리한다. 농민 개인정보는 업체에 직접 제공하지 않는다. 관리자 CMS와 업체 CMS를 분리하며, 현재 최우선 개발 대상은 작물영양관 메인·브랜드 전체보기·브랜드관 관리 시스템이다. 핵심 철학은 “상품이 아니라 브랜드를 전시한다”이며 모바일 중심, 단순 구조, 높은 입점 가치가 기준이다.
