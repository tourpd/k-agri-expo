# 프로젝트명

K-AGRI EXPO LIVE 방송 추첨 시스템

# 탄생 배경

오프라인 행사 및 라이브 방송에서 농민 대상 경품 추첨을 진행할 때 기존 방식은 전달력, 가독성, 현장 통제가 부족했다.

# 왜 시작했는가

농민들이 멀리서도 한눈에 보고 이해할 수 있는 방송용 추첨 화면과 운영자 제어 시스템이 필요했기 때문.

# 해결하려는 문제

- 글자가 작아서 안 보임
- 영상·이미지 수동 교체
- 방송 중 수정 불가
- 운영자가 통제 불가
- 하드코딩 구조

# 기존 방식의 한계

- PPT 진행
- 엑셀 진행
- 수기 진행
- 실시간 수정 불가
- 방송 연동 어려움
- OBS 활용성 부족
- 농민 기준 UI 부재
- 반복 작업 과다

# 핵심 철학

"농민이 멀리서도 바로 이해하는 화면"

"운영자가 방송 중 모든 것을 제어하는 시스템"

# 무엇을 가장 중요하게 보는가

- 상품 판매 연결
- 라이브 활성화

# 베이스캠프 요약

K-AGRI LIVE 방송 추첨 시스템은 농민 대상 라이브 방송과 오프라인 행사에서 사용하는 방송형 추첨 플랫폼이다. 큰 글씨, 영상 자동화, 실시간 운영자 제어를 중심으로 설계되었으며 하드코딩 없는 CMS 기반 방송 시스템으로 전환했다. 현재 송출 화면과 데이터 연결은 완료되었고, 다음 단계는 경품 수정 CMS, OBS 최적화, 방송 운영 기능 고도화다. 장기적으로는 K-AGRI 라이브커머스, 공동구매, 이벤트, 농민 참여 프로그램의 핵심 엔진으로 활용한다.
