# 프로젝트명

K-AGRI EXPO 미래식량관 고도화 (곤충산업·아카데미·스마트사육농장·청년농 프로젝트)

---

# 탄생 배경

미래식량관을 단순 곤충 홍보관이 아닌 농민의 미래 소득과 청년 유입을 만드는 미래농업 플랫폼으로 전환.

---

# 왜 시작했는가

농산물 생산만으로는 농촌 지속성이 어렵고, 청년 유입·미래소득·신산업 모델이 필요하기 때문.

---

# 해결하려는 문제

- 농촌 고령화
- 청년농 부족
- 농산물 단일소득 구조
- 곤충산업 진입장벽
- 교육·실습·수매 연계 부재

---

# 기존 방식의 한계

- 곤충사육 교육과 사업이 분리됨
- 수매 보장 없음
- 개인 창업 중심
- 체험성 교육 위주
- 미래산업 연결 부족

---

# 핵심 철학

농사를 물려주지 마십시오. 미래를 물려주십시오.

생산자 → 경영자 → 산업가

---

# 무엇을 가장 중요하게 보는가

- 실제 사업화
- 수매 연결
- 검증 후 확장
- 청년 공동창업
- KFFR 생태계 구축

---

# 주요 결정사항

- 곤충은 갈색거저리 단일 집중
- 문산 실습센터 실사진 활용
- KFFR 로고 적용
- 컨테이너 스마트 사육장 모델 채택
- 교육 → 실습 → 생산 → 수매 → 사업화 구조 확정

# K-AGRI 전체에서의 의미

---

# 이 프로젝트가 전체 K-AGRI 구조에서 담당하는 역할

작물 중심 농업에서

- 미래단백질
- 곤충산업
- 청년창업
- 건강산업

으로 확장하는 미래성장 엔진.

---

# 베이스캠프 요약

미래식량관은 곤충 판매관이 아니다. 갈색거저리를 중심으로 교육, 실습, 스마트 사육, 수매, 건강산업까지 연결하는 KFFR 미래농업 플랫폼이다. 문산 실습센터를 실증 거점으로 활용하고, 컨테이너형 스마트 사육장을 표준 모델로 채택했다. 청년농 프로젝트는 단순 귀농이 아니라 청년 10명이 모여 50억 미래농업 프로젝트를 만드는 공동창업 모델로 확정했다. 최종 구조는 곤충산업 → 아카데미 → 스마트사육장 → 치유농업 → 청년농 프로젝트 → 건강산업 → 정착마을 순서로 정리되었다.
