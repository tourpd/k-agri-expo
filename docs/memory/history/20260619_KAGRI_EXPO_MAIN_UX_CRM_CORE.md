# 프로젝트명

K-Agri Expo 메인 UX 재설계 + CRM 코어 완성 프로젝트

---

# 탄생 배경

기존 K-Agri Expo가 박람회형 화면, 카드 나열형 구조, 업체 소개 중심으로 구성되어 있었음.

농민·기업·바이어가 들어와도 무엇을 해야 하는지 즉시 이해하지 못하는 문제가 발견됨.

동시에 문의 → 리드 → 상담 → 계약으로 이어지는 CRM 기반 운영체계 구축 필요성이 커짐.

---

# 왜 시작했는가

- 방문자를 행동으로 전환
- 농민 문의를 CRM 자산화
- 기업 상담을 매출로 연결
- 바이어를 거래로 연결
- 운영자가 콘텐츠를 직접 통제

---

# 해결하려는 문제

- 박람회처럼 보이지만 행동 유도가 약함
- 문의 데이터가 흩어짐
- 리드 우선순위 없음
- 운영자가 이벤트/배너 관리 어려움
- 메인 화면 정보 과다

---

# 기존 방식의 한계

- 업체 카드 나열
- 이벤트 페이지 단순 노출
- CRM 없음
- 상담 이력 관리 없음
- HOT 고객 식별 불가
- 로그인 구조 불명확

---

# 베이스캠프 요약

K-Agri Expo는 더 이상 업체 소개 사이트가 아니다.

농민·기업·바이어가 들어오자마자 자신의 목적을 선택하고 행동으로 이동하는 플랫폼으로 재설계 중이다.

CRM 코어는 완성 단계이며 문의 → 리드 → 상담 → 계약 흐름이 구축되었다.

메인 화면은 기존 박람회형 구조를 폐기하고 선택형 UX로 전환한다.

고정 이미지와 업체 나열은 줄이고 운영형 배너(이벤트·신제품·라이브·입점모집)를 CMS로 관리한다.

향후 K-Agri Expo는 농업 정보, 상담, 거래, 판매, 이벤트를 연결하는 K-AGRI 전체의 메인 게이트웨이 역할을 담당한다.
