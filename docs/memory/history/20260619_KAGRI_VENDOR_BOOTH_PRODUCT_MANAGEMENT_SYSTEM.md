# 프로젝트명

K-AGRI EXPO 업체 부스·제품 관리 시스템 고도화

---

# 탄생 배경

기존 브랜드관/부스 관리 기능은 있었지만 실제 업체가 직접 제품을 등록·수정·삭제하고 이미지·카탈로그를 업로드하는 판매 운영 기능이 부족했음.

---

# 왜 시작했는가

- 업체가 직접 부스를 관리하게 하기 위함
- 운영자 개입 최소화
- 제품 등록 자동화
- 공동구매·행사상품 운영
- AI 판매자동화센터와 연결

---

# 해결하려는 문제

- 제품 등록 불편
- 이미지 업로드 불가
- 카탈로그 관리 불가
- 업체별 권한 검증 부족
- 부스 소유권 검증 부족
- 제품 수정/삭제 안정성 부족

---

# 기존 방식의 한계

- URL 입력 중심
- 파일 업로드 기능 부족
- product_id / id 혼재
- 권한 검증 취약
- 부스와 제품 연결 구조 불안정
- 업체가 직접 운영하기 어려움

---

# 핵심 철학

# 베이스캠프 요약

K-AGRI EXPO 업체 부스·제품 관리 시스템은 업체가 직접 제품을 등록·수정·삭제하고 이미지·카탈로그를 업로드할 수 있도록 구축된 판매 운영 시스템이다.

제품관리 컴포넌트(VendorProductManager), 제품 저장 API(upsert), 제품 삭제 API(delete), 파일 업로드 API(upload)를 분리하여 구조를 안정화했다.

권한 검증은 booth 소유권 기준으로 수행하며 expo_products와 expo-assets를 중심으로 운영된다.

Free 1개, Basic 3개, Premium 10개 제품 제한 정책을 적용했다.

현재 CRUD와 업로드 기능은 완료되었으며 다음 단계는 주문·문의·CRM·AI 판매자동화 연결이다.

K-AGRI 전체에서는 브랜드관을 실제 판매 플랫폼으로 전환시키는 핵심 기반 역할을 담당한다.
