# 프로젝트명

K-AGRI AI 두뇌센터 / 농민 행동엔진

## 탄생 배경

K-AGRI가 단순 박람회·쇼핑몰·콘텐츠 사이트가 아니라, 농업 데이터와 현장 판단을 기반으로 농민의 행동을 돕는 운영체제로 가야 한다는 방향이 확정됨.

## 왜 시작했는가

안이영 소장의 농민교육 자료, 병해충 자료, 홍산마늘 프로젝트, 한국농수산TV 현장 영상 등이 흩어져 있고, 이를 콘텐츠·상담·경보·거래로 연결하지 못하고 있었기 때문.

## 해결하려는 문제

- 자료는 많지만 AI가 활용 가능한 판단 데이터가 아님
- 농민에게 “오늘 무엇을 해야 하는가”를 바로 알려주지 못함
- 콘텐츠 생산이 조세환 PD 개인 판단에 과도하게 의존
- 뉴스·쇼츠·웹툰·상담·판매가 원천 데이터와 연결되지 않음

## 기존 방식의 한계

- 새 페이지·새 센터를 계속 만드는 방식은 의미 없음
- 콘텐츠 수량 중심 사고 폐기
- 설명용 화면, 비전 박스, 생산라인 소개 도식은 운영자에게 불필요
- 판단 없는 CG·성우·영상 생산은 콘텐츠 쓰레기 공장이 됨

## 핵심 철학

자료 → 데이터 → 판단규칙 → 행동지시 → 콘텐츠 → 농민 행동

K-AGRI의 핵심은 콘텐츠 생산이 아니라 농민을 움직이는 진실·근거·판단 데이터다.

## 무엇을 가장 중요하게 보는가

- 데이터와 연구결과
- 현장 사례
- 조세환 PD의 판단력
- 농민이 오늘 해야 할 행동
- 공동편집구역의 채택·보류·폐기 판단

## 주요 결정사항

- /admin/knowledge-assets를 농업 AI 두뇌센터로 승격
- 안이영 고추 PPT를 1호 두뇌 자산으로 지정
- 핵심 추출 필드 확정
  - 작물
  - 월
  - 생육단계
  - 증상
  - 원인
  - 대책
  - 작업지시
- 안이영 자료의 핵심은 뉴스·쇼츠 개수가 아니라 5월~10월 월별 작업지시서
- 공동편집구역은 글 수정 공간이 아니라 판단 엔진

## 폐기한 아이디어

- 새 센터 계속 추가
- CG실·성우실·영상실을 먼저 만드는 방향
- 콘텐츠 생산량 중심 자산센터
- “진실센터”라는 탐사보도식 화면
- 설명용 생산라인 카드

## 구현 완료

- /admin/knowledge-assets 기존 파일 확인
- 기존 콘텐츠 수량 중심 화면의 문제 확인
- 농업 AI 두뇌센터 방향으로 코드 교체 진행
- 안이영 고추 PPT 1차 분석 완료
- PPT가 고추 생육관리·병해충·월별 작업지시서·방제력 자료임을 확인

## 현재 상태

K-AGRI는 페이지를 늘리는 단계가 아니라, 안이영 자료를 AI가 활용 가능한 농민 행동 데이터로 분해하는 단계에 들어섰다.

## 다음 단계

1. 안이영 고추 PPT에서 5월~10월 작업지시서 추출
2. 월별·생육단계별 행동지시 DB화
3. 병해충 판단규칙 추출
4. 공동편집구역에서 채택·보류·폐기 기준 적용
5. 농사119·작가실·뉴스·쇼츠·문자에 공급

## K-AGRI 전체에서의 의미

이 프로젝트는 K-AGRI의 두뇌다.

브랜드관·거래소·뉴스·작가실·농사119가 모두 이 두뇌의 데이터를 활용하게 된다.

## 베이스캠프 요약

K-AGRI는 박람회나 쇼핑몰이 아니라 대한민국 농업 데이터·판단·행동 엔진이다. 지금 핵심은 새 페이지를 만드는 것이 아니라 안이영 자료, 병해충 자료, 홍산마늘 프로젝트, 한국농수산TV 현장 자료를 AI가 활용 가능한 판단 데이터로 바꾸는 것이다. /admin/knowledge-assets는 콘텐츠 자산센터가 아니라 농업 AI 두뇌센터로 승격한다. 1호 자산은 안이영 고추 생육관리와 병충해방제 PPT이며, 핵심 보물은 5월~10월 월별 작업지시서다. 최종 목표는 농민에게 “오늘 무엇을 해야 하는가”를 알려주는 농민 행동엔진 구축이다.
