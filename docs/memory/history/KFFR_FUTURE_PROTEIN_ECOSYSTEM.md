# 베이스캠프 요약

KFFR, 한미양행, 한국농수산TV를 중심으로 미래단백질 산업 생태계를 구축한다. 미래단백질 건강산업관과 청년농 프로젝트를 미래식량관 핵심 콘텐츠로 확정했다. 미래단백질은 생산·교육·가공·건강식품·소비를 연결하는 산업 모델이며, 청년농 프로젝트는 남녀 10명이 귀농·창업·콘텐츠·연애를 함께 만들어가는 새로운 농촌 성장 모델이다. 목표는 곤충산업 홍보가 아니라 농민 소득, 청년 유입, 건강산업을 동시에 만드는 미래농업 생태계 구축이다.
