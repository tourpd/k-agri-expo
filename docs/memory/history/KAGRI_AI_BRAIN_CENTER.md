# 프로젝트명

K-AGRI AI 두뇌센터 - 대용량 지식자산 자동 색인 및 AI 작가실 엔진

# 탄생 배경

안이영 소장 농민교육 자료, 병해충 자료, 강의 PPT, PDF, HWP 등 방대한 농업 지식자산을 사람이 직접 읽고 콘텐츠화하는 데 한계가 발생. 150개 이상의 대용량 자료를 AI가 자동 분석하여 농민 행동지시·방송소재·쇼츠소재로 전환하기 위해 시작.

# 왜 시작했는가

- 안이영 30년 농민교육 자료 자산화
- 조세환 PD의 판단력을 데이터화
- 한국농수산TV 콘텐츠 생산 자동화
- 농민에게 즉시 활용 가능한 행동지시 제공

# 해결하려는 문제

- 대용량 PPT 분석 불가
- 자료는 많지만 활용이 어려움
- 콘텐츠 기획이 사람 의존적
- 병해충·생리장해 정보를 즉시 활용하기 어려움

# 기존 방식의 한계

- PPT → PDF → OCR → 저장을 단일 API에서 처리
- 300~500페이지급 파일 타임아웃 발생
- 수동 이미지 분석 필요
- 사람이 직접 자료를 읽고 콘텐츠 선정

# 핵심 철학

- 자료 → 데이터 → 판단규칙 → 행동지시 → 콘텐츠
- 농민에게 도움이 되는 정보가 최우선
- AI가 먼저 분석하고 사람은 검수만 한다
- 콘텐츠 생산보다 판단엔진 구축이 핵심

# 무엇을 가장 중요하게 보는가

- 농민 행동지시 가능성
- 병해충·생리장해 정보
- 시기성
- 수익 연결성
- 품질 향상 가능성
- 방송·쇼츠 소재성
- 안이영 고유 노하우 여부

# 주요 결정사항

- Job Queue 방식 채택
- knowledge_file_jobs 도입
- 전체 페이지 텍스트 색인
- 중요도 기반 TOP 페이지 선별
- TOP 페이지 자동 이미지 AI 분석
- knowledge_page_index 중심 구조 채택
- AI 작가실 자동 생성 방향 확정

# 폐기한 아이디어

- 앞 20페이지만 추출
- 전체 페이지 이미지 저장 후 수동 분석
- 단일 API 일괄 처리 방식

폐기 이유:
- 중요 정보 누락
- 대용량 처리 불가
- 자동화 수준 부족

# 구현 완료

- knowledge_file_jobs 구축
- 대용량 PPT Job Queue 처리
- PDF 변환
- 텍스트 추출
- 이미지 추출
- importance_score 계산
- shorts_score 계산
- broadcast_score 계산
- knowledge_page_index 저장
- TOP 페이지 자동 선별
- 자동 이미지 분석
- 판단규칙 자동 생성
- finalize-job 1차 구현

# 현재 상태

- 372페이지 고추-화촌농협 PPT 처리 성공
- 약 54,431자 추출
- 372페이지 색인 완료
- 고가치 페이지 34개 선별
- 판단규칙 34건 저장 완료
- 방송소재/쇼츠소재 저장 로직 수정 필요

# K-AGRI 전체에서의 의미

K-AGRI의 모든 데이터, 콘텐츠, 상담, 농사119, 작가실, 뉴스, 쇼츠의 원천이 되는 중앙 두뇌 엔진. 단순 자료보관소가 아니라 농업 판단과 콘텐츠 생산을 담당하는 핵심 시스템.

# 베이스캠프 요약

안이영 농민교육 자료를 시작으로 대용량 농업 자료를 자동 색인하고, 중요도를 평가하여 판단규칙·행동지시·방송소재·쇼츠소재로 변환하는 AI 두뇌센터를 구축했다. 현재 372페이지급 PPT 처리와 중요 페이지 선별까지 성공했으며, 다음 단계는 AI 작가실 구축과 콘텐츠 자동 생산 체계 완성이다.
