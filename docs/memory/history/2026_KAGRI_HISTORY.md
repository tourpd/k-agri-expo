
# 한국농수산TV 농민 집단지성 자산화 프로젝트 (철수 엔진·옥암리 엔진 베이스캠프)

## 탄생 배경
- 한국농수산TV 1,393편 영상 보유
- 안이영 자료처럼 한국농수산TV 자체를 지식자산으로 전환 필요
- 철수·최만수 캐릭터가 상상이 아닌 실제 농민 데이터 기반으로 만들어져야 함

## 왜 시작했는가
- 농민은 무엇에 공감하고 댓글을 다는지 데이터화 필요
- 조세환 PD 개인 경험과 전화 네트워크를 시스템 자산으로 전환
- 유튜브 채널을 넘어 농민 판단엔진 구축

## 해결하려는 문제
- 농민의 실제 언어와 고민이 기록되지 않음
- 캐릭터가 작가 상상에 의존
- 농민 심리·감정·결정 패턴 데이터 부재
- 현장 정보가 PD 개인에게 집중

## 기존 방식의 한계
- 제품 중심 콘텐츠
- 강의형 콘텐츠
- 경험 기반 직관 의존
- 전화·인맥 중심 정보 수집

## 핵심 철학
- 철수를 만드는 것이 아니라 발견한다.
- 캐릭터보다 농민 데이터가 먼저다.
- 정보보다 공감이 먼저다.
- 한국농수산TV는 농민 집단 기억 저장소다.

## 무엇을 가장 중요하게 보는가
1. 농민 감정
2. 농민 고민
3. 행동 유발
4. 댓글 유발
5. 공감 유발
