# 프로젝트명
K-AGRI EXPO 입점승인센터 · 브랜드관 자동생성 시스템

# 탄생 배경
K-AGRI EXPO 참여 업체가 늘어나면서 신청접수, 입금확인, 승인, 브랜드관 생성, 부스 배정을 수작업으로 처리하기 어려워짐.

# 왜 시작했는가
입점 신청 후 관리자가 여러 화면을 오가며 처리하던 업무를 하나의 관리자 관제센터에서 처리하기 위해.

# 해결하려는 문제
- 입점 승인 업무 비효율
- 입금 확인 누락
- 브랜드관 생성 지연
- 부스 배정 관리 어려움
- 사업자등록증 검수 불편

# 기존 방식의 한계
- 신청서, 결제, 브랜드관이 분리됨
- 승인 후 브랜드관 수동 생성
- 상태 추적 어려움
- 대량 업체 관리 불가능
- 카드형 UI로 한눈에 파악 어려움

# 핵심 철학
"신청 → 결제 → 승인 → 브랜드관 → 부스"를 원클릭 자동화한다.

# 무엇을 가장 중요하게 보는가
- 관리자 생산성
- 엑셀형 대량관리
- 승인 즉시 브랜드관 생성
- 모바일 대응
- 상태 추적 가능성

# 주요 결정사항
- 카드형 폐기
- 엑셀형 관리자 화면 채택
- 업체별 상세 모달 제공
- 승인과 브랜드관 생성 통합
- 사업자등록증 미리보기 지원
- 부스 생성 기능 통합
- 슬롯 배정 기능 포함
- 반려사유 저장 기능 포함

- 업체 상세정보 조회
- 사업자등록증 조회
- 상태 필터
- 통합 검색
- 승인 처리
- 입금 확인 처리
- 반려 처리

실데이터 연결 및 운영 테스트 단계.

# K-AGRI 전체에서의 의미
K-AGRI에 기업을 유입시키는 첫 관문.
모든 브랜드관 생성의 출발점.

# 이 프로젝트가 전체 K-AGRI 구조에서 담당하는 역할
업체 유입 → 승인 → 브랜드관 생성 → 박람회 입점까지 연결하는 운영 허브.

# 베이스캠프 요약
K-AGRI EXPO 입점승인센터는 신청업체를 엑셀형 관리자 화면에서 통합 관리하는 운영 관제 시스템이다. 신청접수, 입금확인, 승인, 반려, 사업자등록증 검수, 브랜드관 자동생성, 부스 생성, 슬롯 배정을 한 화면에서 처리한다. 카드형 UI는 폐기하고 대량 데이터 운영이 가능한 표 기반 구조를 채택했다. 현재 승인과 동시에 브랜드관을 자동 생성하는 구조까지 연결되었으며, 향후 이메일·SMS 자동화와 업체 계정 자동 생성까지 확장 예정이다.
