# 탄생 배경

기존 온라인 박람회 구조만으로는 농민의 실제 구매와 상담 행동을 끌어내기 어렵다는 판단.

농민은 부스 위치를 찾아다니지 않고 문제 해결, 전화 상담, 추천 제품을 원함.

---

# 왜 시작했는가

- 농민의 구매 전환율 향상
- 업체의 매출 증대
- 대표의 영업 자동화
- 상담 데이터 자산화
- K-AGRI를 단순 박람회가 아닌 판매 플랫폼으로 발전

---

# 해결하려는 문제

- 업체 상담 인력 부족
- 반복적인 제품 문의
- 상담 내용 누락
- 주문 관리 비효율
- 판매 후 고객관리 부재

---

# 베이스캠프 요약

K-AGRI EXPO는 더 이상 온라인 전시장이 아니다.

농민이 전화로 상담하고 AI가 영업사원처럼 응대하며 제품 추천, 주문 생성, 배송, 재구매까지 연결하는 농업 판매자동화 플랫폼으로 방향을 확정했다.

메인화면은 경품 → 특가 → AI상담 → 포토닥터 → 라이브 → 추천관 중심으로 재설계한다.

농자재관은 A1/A2/A3 부스 구조를 폐기하고 작물별·시기별·기능별 구조로 전환한다.

상담CRM을 통해 상담내용, 작물, 지역, 평수, 추천제품, 주문상태를 저장하고 업체별 매출과 정산까지 자동화한다.
