# 04-03. K-AGRI Knowledge Graph V1

## 핵심 결론

K-AGRI는 농업 정보를 저장하는 시스템이 아니다.

K-AGRI는 대한민국 농업 현실을 학습하고,
농민에게는 해결책을,
기업에게는 시장을,
콘텐츠팀에게는 소재를,
사업팀에게는 기회를 제공하는 농업 운영체제다.

---

## 핵심 구조

모든 데이터는 아래 구조에 연결한다.

농민 → 작물 → 상황 → 문제 → 원인 → 해결 → 결과 → 감정

## 제품과 협찬 연결 원칙

제품은 중심이 아니다.

제품은 농민 문제를 해결하는 도구다.

따라서 PPL과 협찬은 광고가 아니라
데이터 기반 문제 해결 캠페인으로 설계한다.

---

## 사업 제안 구조

기업이 들어오면 아래 항목을 제안한다.

- 해당 제품이 해결하는 농민 문제
- 적용 가능한 작물
- 적용 가능한 시기
- 관련 지역
- 관련 문의 수
- 관련 콘텐츠 수
- 예상 캠페인 기간
- 예상 리드 수
- 예상 상담 수
- 예상 비용
- 예상 ROI

---

## 철수 엔진 연결

철수는 데이터가 아니다.

철수는 K-AGRI 지식그래프를 농민에게 전달하는 인터페이스다.

상황 → 철수 투입 → 반전 → 공감 → 행동

---

## 최종 목표

K-AGRI가 스스로 말해야 한다.

이번 주 어떤 작물에 문제가 늘고 있는지,
어떤 농민들이 힘들어하는지,
어떤 콘텐츠를 만들어야 하는지,
어떤 제품과 연결할 수 있는지,
어떤 사업 제안을 해야 하는지.

이것이 K-AGRI Knowledge Graph의 목적이다.
