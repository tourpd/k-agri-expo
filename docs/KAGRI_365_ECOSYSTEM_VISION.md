# K-AGRI 365 ECOSYSTEM VISION

상태: MASTER VISION LOCK CANDIDATE

## 1. K-AGRI의 최종 목적

K-AGRI는 온라인 박람회, 쇼핑몰, AI 상담, 영상 편집기 중 하나가 아니다.

K-AGRI의 최종 목적은

**농민 × 농업기업 × 소비자 × 국내외 바이어 × 전문가/지식이
365일 하나의 공간에서 연결되는 대한민국 농업 통합 플랫폼**

을 만드는 것이다.

모든 기능은 이 목적에 기여해야 한다.

## 4. K-AGRI EXPO의 역할

K-AGRI EXPO는 단순 쇼핑몰이 아니다.

**대한민국 농업의 산업 광장**이다.

기업이 참가하고,
농민이 기술과 제품을 발견하고,
소비자가 생산자를 만나고,
국내외 바이어가 한국 농업을 발견하는 공간이다.

핵심 기능:

- 기업 전시
- 제품/기술 전시
- 농민 문제 해결
- 현장 검증 콘텐츠
- 상담
- 바이어 연결
- 농산물 발견
- B2B
- 수출 연결

## 5. K-AGRI 365의 역할

EXPO가 만남의 공간이라면

**K-AGRI 365는 그 만남이 365일 계속되는 거래와 관계의 공간이다.**

EXPO
→ 발견

365
→ 지속 관계와 거래

K-AGRI 365는 단순 상품 나열형 쇼핑몰로 만들지 않는다.

농민에게는

작물
→ 시기
→ 문제
→ 지식
→ 현장 사례
→ 해결방법
→ 필요한 경우 관련 제품
→ 구매
→ 결과

순으로 연결한다.

소비자에게는

농가
→ 생산과정
→ 콘텐츠
→ 농산물
→ 구매

로 연결한다.

바이어에게는

생산자/기업
→ 품목
→ 공급능력
→ 검증정보
→ 수요
→ 매칭
→ 견적
→ 거래

로 연결한다.

- 농산물 발견

- 바이어에게 한국 농업을 보여주는 미디어

## 7. JOPD AI ENGINE의 역할

JOPD AI ENGINE은 독립적인 영상 편집툴을 만드는 것이 목적이 아니다.

K-AGRI 전체 생태계의 콘텐츠 생산 엔진이다.

촬영 전:

K-AGRI 지식
+ 과거 한국농수산TV

+ 기업/제품
+ 시장/바이어 정보

→ 사전 작가실
→ 취재 방향
→ 질문
→ 검증 포인트
→ 촬영 작전서

촬영 후:

원본
→ VIDEO BRAIN
→ 전체 촬영 이해
→ K-AGRI 지식 연결
→ JOPD EDITING DNA
→ PD ENGINE
→ 구성
→ 실제 가편
→ 보완
→ 완성 방송

방송 후:

콘텐츠
→ EXPO
→ 농민
→ 기업
→ 소비자
→ 바이어
→ 상담/거래
→ 결과 데이터

로 연결한다.

## 8. 포토닥터의 역할

포토닥터는 단순 사진 진단 기능이 아니다.

**농민의 실제 문제를 K-AGRI가 감지하는 현장 센서**다.

농민 문제
→ 사진/질문
→ 진단 후보
→ 전문가/공식 지식
→ 관련 현장 사례
→ 관련 콘텐츠
→ 상담
→ 필요한 경우 제품
→ 결과

제품 판매를 먼저 하지 않는다.

진단과 정보가 먼저다.

## 11. 개발 판단 기준

새 기능을 만들기 전에 반드시 묻는다.

1. 누가 사용하는가?
2. 왜 사용하는가?
3. 어떤 문제가 해결되는가?
4. 어떤 데이터가 생성되는가?
5. 기존 K-AGRI 데이터와 어디에서 연결되는가?
6. 다음 행동은 무엇인가?
7. 농민·기업·소비자·바이어 중 누구에게 가치가 생기는가?
8. 이 결과가 다시 K-AGRI BRAIN으로 돌아오는가?

이 질문에 답하지 못하는 기능은 우선 개발하지 않는다.

## 12. 개발 금지 원칙

- 하나의 기능에 함몰하지 않는다.
- 독립된 섬 형태의 서비스를 추가하지 않는다.
- 기존 시스템과 중복되는 새 시스템을 만들지 않는다.
- 기존 DB를 이유 없이 갈아엎지 않는다.
- 농민을 단순 구매자로 취급하지 않는다.
- 기업을 단순 광고주로 취급하지 않는다.
- 소비자를 단순 결제자로 취급하지 않는다.
- 바이어를 단순 문의자로 취급하지 않는다.
- 콘텐츠를 조회수만을 위한 결과물로 취급하지 않는다.
- 판매량을 콘텐츠 품질과 동일시하지 않는다.
- AI 추론을 현장 사실로 둔갑시키지 않는다.

## 15. JOPD VIDEO BRAIN의 현재 위치

VIDEO BRAIN은 전체 K-AGRI의 한 부품이다.

현재:

2.0 FULL SOURCE SCAN 완료
2.1 BASE VISUAL COVERAGE 완료
2.2 ADAPTIVE EVENT DETECTOR 진행 중

VIDEO BRAIN의 목적은 영상 분석 자체가 아니다.

**현장의 사실을 정확하게 콘텐츠 데이터로 변환하여
K-AGRI 전체 생태계에 연결하는 것**이다.

## 16. 최종 원칙

K-AGRI의 성공 기준은

기능이 몇 개 있는가가 아니다.

**농민과 기업과 소비자와 바이어가
K-AGRI 안에서 서로 발견하고,
지식을 얻고,
문제를 해결하고,
거래하고,
그 결과가 다시 대한민국 농업의 지식이 되는가**

이다.

K-AGRI는 365일 살아 움직이는
대한민국 농업의 연결망을 목표로 한다.
