# K-AGRI BRAIN 기준점 (2026-06-16)

## 이번에 발견한 치명적 오류

행동지시센터를 농민용 화면처럼 만들었으나
실제 농민은 절대 이런 화면을 보지 않는다.

행동지시센터는 관리자용 데이터센터일 뿐이다.

데이터는 성공.
화면 설계는 실패.

--------------------------------------------------

## 앞으로 개발 순서

반드시 아래 순서를 지킨다.

1. 누가 쓰는가?
2. 사용자가 얻는 결과는?
3. 그 결과를 만들 데이터는?
4. 화면 설계
5. 개발

데이터 먼저 만들고
사용자를 나중에 생각하는 실수 금지.

--------------------------------------------------
