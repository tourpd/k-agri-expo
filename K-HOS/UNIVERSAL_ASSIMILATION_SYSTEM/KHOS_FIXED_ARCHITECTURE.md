# K-HOS FIXED ARCHITECTURE

K-HOS는 성경 분석기가 아니다.
K-HOS는 농업 분석기가 아니다.
K-HOS는 인간성 분석기가 아니다.

K-HOS는 어떤 자료가 들어와도
그 자료의 성격을 먼저 판단하고,
그 자료 안의 사건, 지식, 개념, 방법, 데이터, 인물, 교훈, 창작 가능성을
우리 시스템 안에서 다시 사용할 수 있게 구조화하는
UNIVERSAL ASSIMILATION SYSTEM이다.

## 절대 원칙

1. 하드코딩 금지
2. 샘플 데이터 삽입 금지
3. 자료 종류 사전 가정 금지
4. 모든 입력은 PRE-SCAN 먼저 수행
5. AI가 DOMAIN과 CATEGORY를 스스로 제안
6. 기존 분류가 없으면 새 분류 생성
7. 결과는 작가실, 사업실, 교육실, 농업실에서 재사용 가능해야 함
8. 모든 진행상황은 COMMAND CENTER에 표시
9. 원본은 반드시 보존
10. 분석 결과는 검색 가능한 구조로 저장
