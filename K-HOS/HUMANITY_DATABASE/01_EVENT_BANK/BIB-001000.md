# BIB-001000

TITLE
각 지파에서 한 족장을 택하라는 명령

CHARACTERS
모세
이스라엘 자손
각 지파 대표

BEGINNING
모세에게 각 지파의 대표 선출 명령이 전해진다.

DEVELOPMENT
분배 실무를 위해 매 지파마다 한 족장을 택하라고 지시한다.

CONFLICT
대표성 부족 시 불만이 생길 수 있기에 지파 참여가 필수다.

CHOICE
각 지파가 자신들의 족장을 공적으로 세운다.

ENDING
분배 참여 구조(지파 대표 체계)가 확정된다.

LESSON
대표성과 참여는 공동체 결정을 정당화하고 수용성을 높인다.

THEMES
대표성
참여
절차적 정당성
사회적 합의

WRITER ROOM
지파별 회의 몽타주—지도 뒷배경에서 손을 들어 대표를 추대.
