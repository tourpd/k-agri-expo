# BIB-000880

TITLE
공개 검증: 지팡이 회수

CHARACTERS
모세
이스라엘 모든 자손
각 지파 족장들
아론

BEGINNING
모세가 회막에서 지팡이들을 가지고 나와 백성 앞에 선다.

DEVELOPMENT
모든 백성이 표징을 보고 각자 자신의 지팡이를 회수한다.

CONFLICT
공동체가 표징을 받아들이고 더 이상의 시비를 멈출 수 있는가.

CHOICE
백성은 눈으로 확인하고 결과를 수용한다.

ENDING
공개 검증으로 논쟁의 여지가 사라진다.

LESSON
공개성과 투명성은 공동체적 합의를 가능케 한다.

THEMES
공개성
공동체 합의
권위 수용

WRITER ROOM
대중의 웅성거림이 침묵으로 바뀌는 순간 포착. 지도자들의 표정 변화로 수용의 정서를 시각화.
