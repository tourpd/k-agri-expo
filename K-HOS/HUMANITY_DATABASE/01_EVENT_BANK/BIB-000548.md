# BIB-000548

TITLE
백성의 자원 봉헌과 기술 참여

CHARACTERS
이스라엘 남녀
마음이 감동된 자들
슬기로운 여인들
모든 족장
모세

BEGINNING
온 회중이 모세 앞에서 물러나 각자의 장막으로 돌아간다.

DEVELOPMENT
마음이 감동되고 자원하는 자들이 금붙이(가슴 핀, 귀고리, 가락지, 목거리 등), 실과 가죽, 은과 놋, 조각목을 가져온다. 슬기로운 여인들은 청색·자색·홍색실과 가는 베, 염소털을 손수 잣아 바친다. 족장들은 호마노와 에봇·흉패 보석, 등불의 기름과 관유, 분향할 향품을 들인다.

CONFLICT
개인의 소유와 안락함을 내려놓고 공동체의 거룩한 목적에 참여할지의 시험.

CHOICE
남녀, 평민과 지도자, 장인과 주부에 이르기까지 각자 가진 것과 기술을 기쁘게 드리기로 선택한다.

ENDING
필요한 재료와 기술이 풍성히 모아져 여호와께 즐거이 드려진다.

LESSON
자원하는 마음이 공동체 전체를 움직이며, 각자의 고유한 몫이 성소를 세운다.

THEMES
자발성
관대함
공동체 참여
기술 봉사
기쁨의 헌신

WRITER ROOM
장막 골목마다 봉헌 행렬이 이어지고, 베를 잣는 손길과 반짝이는 금이 한곳으로 모인다. 웃음과 눈물이 뒤섞인 기쁨의 웅성거림.
