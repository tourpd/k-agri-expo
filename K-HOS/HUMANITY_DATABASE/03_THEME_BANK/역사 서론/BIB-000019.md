# BIB-000019

TITLE
결론: 노아 자손에게서 열국이 분화

CHARACTERS
노아의 자손(총칭)

BEGINNING
앞선 모든 목록이 노아 자손의 세계적 분포임이 요약된다.

DEVELOPMENT
각 세계와 나라대로 정리된다.

CONFLICT
명시적 갈등 없음.

CHOICE
특정 선택 서술 없음.

ENDING
홍수 후 이들에게서 땅의 열국 백성이 나뉘었음이 선언된다.

LESSON
모든 민족은 하나의 뿌리에서 갈라졌다는 보편적 기원이 강조된다.

THEMES
보편적 기원
민족 분화
역사 서론

WRITER ROOM
톤: 에필로그. 세계 지도 풀샷, 삼색(셈·함·야벳)으로 그라디언트 분포. 레퍼런스: v.32.
