# BIB-001005

TITLE
가나안 입성 후 도피성 제도 확정

CHARACTERS
여호와
모세
이스라엘 자손
타국인
우거하는 자
살인자
회중

BEGINNING
요단을 건너 가나안에 들어간 후를 상정한다.

DEVELOPMENT
의도치 않게 살인한 자가 피할 수 있도록 도피성을 지정한다. 요단 동편 3, 가나안 땅 3. 이스라엘뿐 아니라 타국인과 거류민에게도 적용된다.

CONFLICT
사적 복수의 악순환과 오심(誤審)의 위험.

CHOICE
피의자는 도피성으로 달아나고, 공동체는 성읍을 지정해 보호한다.

ENDING
회중의 판결 전까지 생명이 보호되고 보복이 억제된다.

LESSON
공정한 재판이 성급한 보복보다 우선한다.

THEMES
정의
보호
절차적 정당성
포용성

WRITER ROOM
길 표지판에 ‘도피성’이 적힌 이정표와 성문으로 달려가는 도망자의 실루엣.
