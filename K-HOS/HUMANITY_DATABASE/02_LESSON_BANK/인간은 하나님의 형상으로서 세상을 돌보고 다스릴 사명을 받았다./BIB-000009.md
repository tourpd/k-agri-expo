# BIB-000009

TITLE
여섯째 날(중) — 하나님의 형상대로 사람 창조와 다스림의 위임

CHARACTERS
하나님
사람(남자와 여자)
바다의 고기
공중의 새
육축
온 땅
땅에 기는 모든 것

BEGINNING
하나님이 의논하시듯 말씀하심: 우리의 형상과 모양대로 사람을 만들자.

DEVELOPMENT
하나님의 형상대로 남자와 여자를 창조하심.

CONFLICT
창조 세계의 대표자와 청지기가 아직 없음.

CHOICE
사람에게 모든 생물을 다스리는 임무를 부여하심.

ENDING
인간의 정체성과 사명이 규정됨.

LESSON
인간은 하나님의 형상으로서 세상을 돌보고 다스릴 사명을 받았다.

THEMES
형상(Imago Dei)
사명
다스림
청지기직

WRITER ROOM
‘우리’의 회의감이 울리고, 사람의 눈에 생기가 들어오며 사명이 선포된다.
