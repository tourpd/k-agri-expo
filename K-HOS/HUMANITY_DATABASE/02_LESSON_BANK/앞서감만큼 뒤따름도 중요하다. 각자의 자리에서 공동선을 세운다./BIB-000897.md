# BIB-000897

TITLE
남편 르우벤 진 배치와 둘째 대열

CHARACTERS
르우벤 지파
시므온 지파
갓 지파
엘리술
슬루미엘
엘리아삽

BEGINNING
남쪽 사분면 배치로 행군의 두 번째 줄이 구성됨.

DEVELOPMENT
르우벤 진 기 아래 르우벤(엘리술, 46,500명), 시므온(슬루미엘, 59,300명), 갓(엘리아삽, 45,650명) 배정.

CONFLICT
선두 지원과 측면 보호를 겸하는 둘째 대열의 부담.

CHOICE
둘째로 진행하며 질서를 보조하기로 함.

ENDING
남편 총계 151,450명, ‘제이대로’ 진행 확정.

LESSON
앞서감만큼 뒤따름도 중요하다. 각자의 자리에서 공동선을 세운다.

THEMES
협력
서열과 역할
순종

WRITER ROOM
남쪽에 붉은 색 띠로 둘째 대열 표시. 자막: ‘총 151,450명, 제이대로.’
