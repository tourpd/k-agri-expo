# HUMAN SOUL ANALYSIS PIPELINE

VERSION: 1.0

==================================================
MISSION
==================================================

우리는 책을 읽지 않는다.

우리는 인간을 분석한다.

==================================================
STEP 1
SOURCE INGESTION
==================================================

입력:

- 환단고기
- 성경
- 천부경
- 삼일신고
- 참전계경
- 주역
- 아리랑
- 역사
- 인터뷰
- 영상
- 인간 경험

OUTPUT:

SOURCE_UNIT

==================================================
STEP 2
EVENT EXTRACTION
==================================================

추출:

- 사건
- 인물
- 선택
- 행동
- 갈등
- 희생
- 철학
- 상징

OUTPUT:

EVENT

==================================================
STEP 3
QUESTION EXTRACTION
==================================================

질문 생성:

인간은 왜?
인간은 어떻게?
인간은 무엇을 위해?

OUTPUT:

HUMAN_QUESTION

==================================================
STEP 4
SOUL MATCH
==================================================

HUMAN SOUL CORE 19 매핑

OUTPUT:

SOUL_VECTOR

예)

LOVE            80
RESPONSIBILITY  40
SACRIFICE       95
HOPE            70

==================================================
STEP 5
SOUL SCORE
==================================================

0~100 점수화

OUTPUT:

SOUL_PROFILE

==================================================
STEP 6
MODERN CASE MATCH
==================================================

고대
      ↓
현대

OUTPUT:

MODERN_CASE

==================================================
STEP 7
CONTENT GENERATION
==================================================

출력:

- 숏츠
- 다큐
- 캐릭터
- 철학
- 교육
- 비즈니스

==================================================
FINAL OUTPUT
==================================================

SOURCE

↓

EVENT

↓

QUESTION

↓

SOUL PROFILE

↓

MODERN CASE

↓

CONTENT

==================================================
K-HOS RULE

우리는 정보를 저장하지 않는다.

우리는 인간 존재의 증거를 저장한다.
