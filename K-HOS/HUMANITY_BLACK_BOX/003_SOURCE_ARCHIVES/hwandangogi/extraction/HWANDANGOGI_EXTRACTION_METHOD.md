# HWANDANGOGI HUMAN SOUL EXTRACTION METHOD

목적:
환단고기를 책으로 요약하지 않는다.
환단고기 안에 담긴 인간의 혼을 HUMAN SOUL CORE 19 기준으로 추출한다.

원칙:
1. 원전 구조를 확인한다.
2. 각 혼에 해당하는 개념, 사건, 인물, 상징을 찾는다.
3. 반드시 인간 질문으로 바꾼다.
4. 현대 사례와 연결한다.
5. K-HOS HUMANITY BLACK BOX에 저장한다.

분석 단위:
- 원전 근거
- 핵심 개념
- 인간의 혼
- 인간 질문
- 현대 사례
- 콘텐츠 활용
- K-HOS 해석

주의:
환단고기의 역사적 진위 여부를 먼저 판정하지 않는다.
우리는 인간 존재 증거와 인간의 혼을 추출한다.
