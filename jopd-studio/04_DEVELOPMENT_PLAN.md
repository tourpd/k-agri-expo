# 조PD AI 방송국 개발계획

## 개발 원칙

처음부터 완전자동 20분 영상을 만들지 않는다.

PD 판단부터 완성한다.

---

# PHASE 1
## 방송 기획 엔진

입력:

기사
PDF
사진
텍스트
URL

출력:

- 핵심 주제
- 타깃
- 제목
- 훅
- 로그라인
- 예상 러닝타임
- 전체 구성표

목표:

자료 하나를 넣으면
10분 방송 제작설계서가 나온다.

---

# PHASE 2
## 자동 작가실

출력:

- 전체 대본
- 내레이션
- 인터뷰 질문
- 자막
- 장면 설명

---

# PHASE 3
## 씬 제작실

각 씬별 자동 분류:

- 실사 필요
- 보유 영상 사용
- 사진 사용
- AI 생성
- 그래픽
- 지도
- 차트

---

# PHASE 4
## 영상 생성 API

영상 제공자 추상화.

Google Veo
OpenAI 영상
기타 공급자

교체 가능한 구조로 개발한다.

---

# PHASE 5
## 자동 편집

FFmpeg / Remotion 기반

자동 처리:

영상 연결
자막
내레이션
BGM
사진 움직임
그래픽
인트로
아웃트로

---

# PHASE 6
## 파생 콘텐츠

긴 영상 하나에서 자동 생성:

- 쇼츠 5개
- 썸네일 3개
- 제목 10개
- 설명
- 챕터
- 커뮤니티 글

---

# PHASE 7
## 조PD 학습 시스템

AI 결과와 조PD 수정본 비교.

반복적으로 수정되는 패턴 저장.

목표:

조PD 전용 PD ENGINE 구축.

---

# 최초 개발 화면

경로:

/studio

파일:

src/app/studio/page.tsx

첫 화면 기능:

1. 채널 선택
2. 자료 입력
3. 영상 길이 선택
4. 방송 유형 선택
5. 추가 지시 입력
6. 방송 만들기

---

# 첫 개발 완료 기준

자료를 넣고 버튼을 누르면

방송 제목
훅
핵심 메시지
10분 구성표

가 화면에 출력되면
PHASE 1 MVP 완료.
