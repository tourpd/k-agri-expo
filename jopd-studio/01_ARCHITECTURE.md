# 조PD AI 방송국 시스템 구조

## 전체 흐름

자료 입력
→ 자료 분석
→ PD 판단
→ 방송 기획
→ 작가실
→ 씬 설계
→ 영상소스 결정
→ AI 영상 생성
→ 자동 편집
→ 검수
→ 본편/쇼츠/썸네일 출력

---

## 1. 자료 입력

지원 대상:

- 기사
- PDF
- 사진
- 촬영 영상
- 음성
- 메모
- 홈페이지 URL
- 유튜브 URL
- K-LIBRARY 자료

---

## 2. 자료 분석 엔진

자료에서 자동 추출:

- 인물
- 장소
- 핵심 사건
- 핵심 숫자
- 문제
- 해결방법
- 갈등
- 반전
- 감정
- 경제적 가치
- 시청자에게 필요한 정보
- 검증이 필요한 주장

---

## 3. PD ENGINE

AI가 방송 제작 전에 판단한다.

질문:

1. 이 방송의 주제는 무엇인가
2. 타깃 시청자는 누구인가
3. 첫 5초 훅은 무엇인가
4. 가장 강한 숫자는 무엇인가
5. 가장 강한 인물은 누구인가
6. 갈등은 무엇인가
7. 반전은 무엇인가
8. 시청자 이익은 무엇인가
9. 어떤 장면을 촬영해야 하는가
10. 어떤 자료화면이 필요한가

---

- 자막
- 클로징

- 기존 영상

- 지도

## 6. 영상 생성 엔진

영상 생성 모델은 교체 가능하게 설계한다.

AI 방송국
→ VIDEO PROVIDER ADAPTER
   → Google Veo
   → OpenAI 영상 모델
   → 기타 영상 생성 모델

특정 업체에 종속되지 않는다.
